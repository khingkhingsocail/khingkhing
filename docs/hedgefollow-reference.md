# HedgeFollow ในหัวข้อการลงทุนของขิงขิง

เพิ่ม HedgeFollow เป็นแหล่งอ้างอิงเพิ่มเติมใน **ขิงขิง → การลงทุน** โดยมีปุ่มเปิดเว็บ คู่มือ และเงื่อนไขการใช้ข้อมูล รายละเอียด Warren Buffett และ Berkshire Hathaway เชื่อมไปหน้าพอร์ตของ Berkshire ส่วน Apple เชื่อมไปหน้า AAPL หุ้นที่แสดงในรายการถือครองมีปุ่มค้นผู้ถือหุ้นบน HedgeFollow โดยสร้าง URL จากสัญลักษณ์หลักทรัพย์ที่ตรวจรูปแบบ ไม่ได้หมายความว่าขิงขิงตรวจข้อมูลทุกหน้าหรือคัดลอกข้อมูลจากหน้าเหล่านั้นมาแล้ว

พอร์ตของ Berkshire เป็นพอร์ตองค์กร ไม่ใช่พอร์ตส่วนตัวหรือผลตอบแทนส่วนบุคคลของ Warren Buffett ข้อมูลตัวเลขและอันดับในขิงขิงยังคงใช้ชุดข้อมูลจากเอกสาร SEC และผู้จัดการกองทุนเดิม ไม่คัดลอกตัวเลขพอร์ต ผล Performance หรืออันดับจาก HedgeFollow ลงฐานข้อมูล และไม่มีการดึงข้อมูลหรือซิงค์อัตโนมัติ

## ข้อจำกัดที่แสดงในแอป

รายงาน Form 13F เป็นข้อมูลหลักทรัพย์ตามเกณฑ์ ณ สิ้นไตรมาส โดยทั่วไปยื่นภายใน 45 วันหลังสิ้นไตรมาส ไม่รวมสถานะขายชอร์ตและไม่ครอบคลุมสินทรัพย์ทุกชนิด จึงไม่ใช่พอร์ตเรียลไทม์หรือผลตอบแทนจริงของบุคคล ข้อจำกัดนี้ตรวจจาก FAQ ของ SEC ข้อ 7, 8, 25 และ 41 [1]

HedgeFollow ระบุว่าเว็บไซต์ใช้เพื่อข้อมูลเท่านั้นและไม่รับประกันความถูกต้องหรือความทันเวลา เงื่อนไขข้อ 2.2, 2.5 และ 2.6 จำกัดการใช้เชิงพาณิชย์ การคัดลอก และการเข้าถึงด้วยบอตโดยไม่มีการอนุญาตตามที่กำหนด จึงใช้เป็นลิงก์เพิ่มเติมเท่านั้นในรอบนี้ หากต้องการนำข้อมูลมาเก็บหรืออัปเดตอัตโนมัติ ต้องมีสิทธิ์จากผู้ให้บริการก่อน หรือใช้ข้อมูลต้นทางจาก SEC และผู้ออกหลักทรัพย์ [2]

ตรวจลิงก์และเงื่อนไขวันที่ **9 ตุลาคม 2026** วันที่นี้เป็นวันตรวจเว็บไซต์ ไม่ใช่วันข้อมูลพอร์ต ไม่เปลี่ยนข้อมูลผู้ใช้หรือบัญชี และไม่เผยแพร่เวอร์ชันใหม่ในรอบนี้
