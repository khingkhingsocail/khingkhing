# ขิงขิง — ตรวจสถิติด้วย AI และหลักฐาน

## ใช้งาน

เปิดแท็บ **ขิงขิง** เลือกโปรไฟล์ของตัวเองบนเบราว์เซอร์นี้ → สถิติที่บันทึก → **แนบหลักฐาน / ตรวจด้วย AI** เลือกรูป JPG/PNG/WebP หรือคลิป MP4/WebM ที่เห็นค่า หน่วย วันที่และชื่อ/handle ชัดเจน ยืนยันการจัดเก็บและการส่งข้อมูลไปบริการ AI ก่อนอัปโหลด จากนั้นกด **ส่งให้ AI ตรวจสอบ** และเลือกให้ค้นเว็บเพิ่มเติม หรือแนบลิงก์หน้า official/แพลตฟอร์มต้นทางเพิ่มเติมได้ไม่เกิน 3 URL

หลักฐานไม่ขึ้นฟีดสาธารณะ เปิดดูได้เฉพาะผู้ถือรหัสแก้โปรไฟล์กับผู้ดูแลที่มี session จริง ผู้ถือรหัสเจ้าของคนใดก็มีสิทธิ์อ่านไฟล์ ไม่ใช่การยืนยันตัวตนของเจ้าของ ควรปิดเลขบัตร เลขบัญชี ที่อยู่ และข้อมูลส่วนบุคคลไม่จำเป็นก่อนส่ง ห้ามแชร์ไฟล์รหัสแก้ การลบหลักฐานทำให้ผลตรวจเดิมไม่ใช้รับรองสถิติอีก แต่ข้อมูลสรุป AI/audit และสำเนาระบบฐานข้อมูลอาจคงอยู่ ไม่ใช่การลบข้อมูลทั้งหมดทุกสำเนา

## สถานะที่เห็น

| สถานะ | ความหมาย |
| --- | --- |
| ยังไม่ส่ง AI | ยังไม่มีผลตรวจเวอร์ชันปัจจุบัน |
| AI กำลังตรวจ | มีงานตรวจที่กำลังประมวลผล |
| AI พบหลักฐานสนับสนุน | AI อ่านค่าที่สอดคล้อง พร้อมผ่านเงื่อนไขเบื้องต้น ไม่ใช่ตรารับรองหรือการพิสูจน์ความแท้ |
| AI พบข้อมูลขัดแย้ง | มีความไม่สอดคล้องตามหลักฐานที่อ่าน ไม่เท่ากับกล่าวหาว่าทุจริต |
| หลักฐานยังไม่เพียงพอ | อ่านค่า/ตัวตนที่ระบุ/หน่วย/ช่วงเวลาได้ไม่ครบ |
| ต้องให้คนทบทวน | เช่น คลิปกีฬา ผลตอบแทนพอร์ต สถิติโลก หรือหลักฐานยังมีความคลุมเครือ |
| ผู้ดูแลรับรองแล้ว | ผู้ดูแลล็อกอินจริงทบทวนและบันทึกเหตุผลสำหรับ snapshot นี้ เป็นการรับรองของชุมชน ไม่ใช่หน่วยงานภายนอก |
| ข้อมูลเปลี่ยน ต้องตรวจใหม่ | claim หลักฐานหรือชื่อ/handle เปลี่ยน ผลเก่า stale และไม่ใช้รับรองสถิติปัจจุบัน |

ตัวกรองบน leaderboard แยก **ทั้งหมด**, **AI พบหลักฐานสนับสนุน**, และ **ผู้ดูแลรับรองแล้ว** ออกจากกัน ค้นชื่อไม่เปลี่ยนอันดับภายในกลุ่มที่เลือก ไม่มีการสร้างคะแนนหรือผลรับรองตัวอย่าง

## ขอบเขตและความแม่นยำ

ใช้โมเดล vision ที่มีจริงใน catalog อ่านภาพที่ server decode แล้ว; วิดีโออ่านเฟรมที่สุ่มไม่เกิน 24 เฟรมต่อคลิปและ 48 ภาพรวม รายงานบอกขอบเขตที่ส่งจริง ไม่อ่านเสียงและไม่ตรวจทุกเฟรม การสุ่มเฟรม **ไม่สามารถพิสูจน์การนับวิดพื้นครบ ระยะวิ่งเต็ม ระดับความเร็วจริง หรือคลิปต่อเนื่องไม่ตัดต่อ** ภาพ screenshot อาจถูกแก้หรือเป็นบัญชีของบุคคลอื่นได้

ค่าที่ AI อ่านเป็นการสังเกต ไม่เปลี่ยนคะแนนใน leaderboard อัตโนมัติ ไม่มีตัวเลข “ความแม่นยำ 99%” เพราะยังไม่มีชุดทดสอบที่ผ่านการสอบเทียบ เราทดสอบ pipeline ด้วยไฟล์ fixture และกรณีหลักฐานไม่สอดคล้อง แต่ไม่ถือว่าพิสูจน์ความแม่นยำของทุกรายการในโลก

ค้นเว็บผ่าน built-in web search และนำ URL citation มาอ่านเนื้อหาหน้าจริงด้วย server ฝั่งระบบ มี URL, excerpt, เวลาเข้าถึง, SHA-256 และระดับแหล่งข้อมูล เช่นองค์กร/สถาบัน แพลตฟอร์มต้นทาง เว็บอื่น ไม่ใช้ snippet หรือความจำของ AI เป็นหลักฐาน การถูกจัดเป็นโดเมนแพลตฟอร์มไม่ได้แปลว่าข้อความผู้ใช้บนแพลตฟอร์มนั้นเชื่อถือได้ทั้งหมด แหล่ง dynamic/login/PDF หรืออ่านไม่สำเร็จจะถูกแจ้งและไม่ใช้เป็นหลักฐาน

สถิติสาธารณะที่อ่านในปัจจุบันไม่จำเป็นต้องเป็นค่าของเดือนเก่า ต้องมีวันที่ยืนยันในหลักฐาน AI-supported ถูกจำกัดเมื่อค่า หน่วย วันที่ ข้อความชื่อ และแหล่งจริงไม่ครบ ยังไม่ยืนยันตัวตน/เจ้าของบัญชี สำหรับลงทุนต้องตรวจ statement วิธีคำนวณและกระแสเงินสด ไม่รับรองจากภาพกำไรอย่างเดียว สถิติโลกต้องหน่วยงานที่เกี่ยวข้องรับรองตามกติกาจริง

## การจัดเก็บและป้องกันข้อผิดพลาด

ไฟล์สูงสุด 20 MiB ต่อไฟล์ 3 ไฟล์ต่อ claim version และรวม 50 MiB ทุกเวอร์ชันรวมสูงสุด 200 MiB และ 100 ไฟล์ต่อโปรไฟล์ หลักฐานเก่าแสดงป้ายและลบได้ (ไม่ส่งตรวจเวอร์ชันใหม่) วิดีโอสูงสุด 3 นาที ภาพ/เฟรมสูงสุด 4096px มี timeout FFmpeg และไม่รันชื่อไฟล์ผ่าน shell เก็บต้นฉบับ BLOB แยกจาก public_media เดิม ไม่มีการเผยแพร่โปรไฟล์/ไฟล์ local-only อัตโนมัติ

Snapshot ผูก revision ของ claim, หลักฐาน, ค่า/หน่วย/วัน/เดือน/URL และชื่อ/handle ผลเก่าจะ stale เมื่อข้อมูลเปลี่ยน มีโควต้า 5 ครั้งต่อโปรไฟล์ต่อวัน retry ไม่เกิน 3 ครั้งต่อเวอร์ชันและ AI พร้อมกันไม่เกิน 2 งานต่อ process ผล timeout/error ไม่กลายเป็น verified ลิงก์ตรวจ SSRF public IP และ pin DNS ทุก redirect จำกัดเวลา/ขนาด หน้าเว็บและข้อความในไฟล์เป็นข้อมูล untrusted ไม่ใช่คำสั่งระบบ

ระบบยังใช้ anonymous bearer profile edit token ผู้ถือรหัสหลายคนอาจเป็นคนเดียวกันหรือคนละคนได้ จึงไม่สามารถยืนยันตัวตนหรือพิสูจน์ความเป็นอิสระของผู้ดูแล/เจ้าของได้สมบูรณ์จาก token เพียงอย่างเดียว ต้องเพิ่มระบบบัญชี/ผูกเจ้าของและ reviewer ก่อนใช้เป็นการแข่งขันที่มีรางวัลหรือการรับรองสาธารณะสำคัญ

## ผู้ดูแล

เปิด **คิวทบทวนหลักฐาน (ผู้ดูแล)** ในแท็บขิงขิง ต้องมีบัญชีใน users ที่ role=admin จาก session Manus จริง ผู้ส่งไม่สามารถตั้ง verified ผ่าน API ได้ ผู้ดูแลต้องอ่านต้นฉบับ ผล AI และแหล่งข้อมูลก่อนตัดสิน มีเหตุผลอย่างน้อย 10 ตัวอักษรบันทึกใน audit และตรวจ snapshot ก่อนรับรอง ไม่มีการสร้างบัญชี admin หรือข้าม login ใน Preview

คิวแสดงล่าสุด 100 รายการ ยังไม่มี pagination/การมอบหมาย reviewer การรับรองควรเป็นอิสระจากเจ้าของผลงาน ไม่ควรใช้คำตอบ AI อย่างเดียว หากถือรหัสแก้เจ้าของใน request จะถูกปฏิเสธการรับรอง; การป้องกัน self-review ที่ผูกบุคคลจริงยังต้องระบบบัญชีเต็มรูปแบบ

## สถานะส่งมอบ

เพิ่ม migration แบบ additive และ API/หน้า UI ใน Preview บันทึกขึ้น main โดยไม่เผยแพร่ build ใหม่ Live website ยังต้อง publish checkpoint เพื่อเปิดให้ผู้ชมทั้งหมดใช้งาน ความสามารถค้นเว็บและ vision ทดสอบผ่านบริการ AI จริงโดยไม่เพิ่มผู้แข่งขันหรือรับรองสถิติปลอม
